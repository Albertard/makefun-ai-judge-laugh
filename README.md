# makefun-ai-judge-laugh

A program that writes one original office-life joke to `/output/entry.txt` — the
whole entry for the make.fun competition **"Make the AI Judge Laugh"**
(`u-rama-melon-make-the-ai-judge-laugh-302d0825`).

## The joke

> The office coffee is so strong it filed its own performance review and got promoted over me.

92 characters. A true office observation (the coffee everyone complains
about) with the turn saved for the last words: the coffee did not just wake
anyone up, it got promoted over the narrator. No pun, no stock line — the
surprise is the promotion, and it reads cleanly aloud in one breath.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
